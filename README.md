# Techium - Landing Page Project

## Overview

**Techium** is a modern, responsive, multi-section web application homepage designed to showcase agency services, portfolio works, company history, latest news, and client testimonials. This project is built using semantic HTML5 structures and custom modular CSS.

## Features

- **Semantic HTML5:** Built using clean, accessible, and structured markup (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
    
- **Responsive Layout:** Designed for optimal viewing across various screen sizes using mobile-first and container-based layout classes.
    
- **Section Modules:**
    
    - **Hero Section:** Prominent call-to-action banner.
        
    - **Services:** Grid layout showcasing agency service offerings.
        
    - **Works (Portfolio):** Visual showcase of projects.
        
    - **About Us:** Information about company values, culture, and process.
        
    - **Latest News:** Blog card previews.
        
    - **Testimonials:** Quotes from clients with avatar support.
        
    - **Contact & Footer:** Location information, social links, and navigational links.
        
- **Dark/Light Theme Hooks:** Attributes included for section-level theme styling (`data-section-theme="dark"`).
    
- **Custom Fonts:** Integrated with Google Fonts (`Open Sans` and `Raleway`).

## Getting Started

### Prerequisites

To run this project locally, all you need is a modern web browser (e.g., Chrome, Firefox, Safari, Edge).

### Installation & Execution

1. **Clone or Download the Repository:**
    
    ```sh
    git clone https://github.com/psalmseins01/sonibaze-frontend.git
    cd sonibaze-frontend
    ```
    
2. **Open in Browser:**
    
    - Double-click `index.html` to open it in your default web browser, or launch it via a live server extension in your editor (e.g., Live Server for VS Code).
        

## Technical Specifications

- **HTML Standard:** HTML5 (valid, semantic markup)
    
- **CSS Architecture:** Custom grid and layout components (`row`, `col-1-3`, `col-1-2`)
    
- **Typography:** `Open Sans` (400, 700) and `Raleway` (700)
    
- **Icons:** Embedded SVG vectors for clean, scalable icons (Facebook, Twitter, Instagram)
